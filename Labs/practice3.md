## Задание 1.
В модели маркетплейса пользователи играют ключевую роль.

В проекте App создайте класс User с полями `id`, `login`, `password`, `name`, `surname`, `inn`, `phone`, `registerDate`.

Сделайте публичный конструктор `public User(string login, string password, string name, string surname, string inn, string phone)`. Как инициализировать поля, которые не передали в параметрах?

Сделайте публичный метод `string GetUserFullName()`, который возвращает строку с именем и фамилией пользователя.

Сделайте публичный метод `public bool TryUpdatePhone(string phone)`, который позволяет менять телефон пользователя и возвращает `true` - если поменять телефон удалось (прошла валидация), `false` - иначе.
Для валидации телефона создайте приватный статический метод `private static bool IsPhoneValid(string phone)` в классе User.

Сделайте поля, которые устанавливаются один раз в момент создания пользователя readonly. Какие это поля?

В Main попробуйте создать пару пользователей через конструктор.

### Задание 3. 
Пользователи готовы совершать покупки. Нам нужна корзина, которую невозможно «сломать» извне, и сервис маркетинга, который имеет эксклюзивный доступ к скрытым скидкам. Внешний код не должен иметь возможность менять цены, удалять товары или применять скидки в обход бизнес-логики.

#### Неизменяемые товары и категории
1. Создай enum `ProductCategory` с атрибутом `[Flags]`: None = 0, Electronics = 1, Clothing = 2, Food = 4, и тд.
2. Создай класс Product. Он должен быть строго неизменяемым (Immutable): свойства `Id`, `Name`, `Price`, `Categories` должны иметь только геттеры (без set и init) и инициализироваться через конструктор.

#### Инкапсуляция состояния корзины
1. Создай класс `ShoppingCart`. Внутри будем хранить товары в приватной коллекции.
2. Реализуй индексатор `public Product this[int index]` для чтения товаров из корзины.
3. Реализуй свойство `TotalPrice` (только геттер), которое пересчитывает сумму всех товаров за вычетом примененной скидки.
4. Добавь методы `AddProduct(Product product)` и `Clear()`.
5. В зависимости от категории товара, будут применяться различные скидки в корзине.
6. Важно: Внешний код не должен иметь возможности получить внутреннюю коллекцию корзины и вызвать `Add` или `Remove` напрямую.

#### Маркетинг, защитное копирование
1. Раздели Solution на два проекта:
    - `Marketplace.Core` (библиотека классов): перенеси сюда `User`, `Product`, `ShoppingCart` и создай класс `MarketingService`.
    - `Marketplace.App` (приложение): здесь останется `Main`. Добавь ссылку на `Marketplace.Core`.
2. В `MarketingService` реализуй метод `public void ApplySecretDiscount(ShoppingCart cart, decimal amount)`.
    - Этот метод должен применять скидку к корзине.
    - Так как менять `TotalPrice` напрямую нельзя, добавь в `ShoppingCart` метод `internal void SetDiscount(decimal amount)`.
    - Убедись, что из `Main` вызвать `cart.SetDiscount()` напрямую нельзя, а через `MarketingService` — можно.
3. Реализуй в `ShoppingCart` метод `public Product[] GetAllProducts()`.
    - Вручную создать новый массив нужного размера, скопировать туда элементы циклом и вернуть его. Это защитит корзину от внешнего вмешательства.
